# 梁挠度、弯矩与应力：梁构件校核入口

[StructuralEngineerLab](https://structuralengineerlab.com) 提供梁与截面相关的在线计算。复核时最常见的是挠度、弯矩与弯曲应力。

优先主题对应工具：

- **梁挠度** — [Beam Deflection Calculator](https://structuralengineerlab.com/tools/beam-deflection-calculator/)：按跨度、刚度与荷载估算挠度；简支/悬臂见 [Simply Supported Beam](https://structuralengineerlab.com/tools/simply-supported-beam-calculator/)、[Cantilever Beam](https://structuralengineerlab.com/tools/cantilever-beam-calculator/)。
- **弯矩** — [Beam Analysis Calculator](https://structuralengineerlab.com/tools/beam-analysis-calculator/)：给定荷载下的梁内力分析入口。
- **应力** — [Beam Bending Stress Calculator](https://structuralengineerlab.com/tools/beam-bending-stress-calculator/)：由弯矩与截面模量估算弹性弯曲应力。

弯曲应力说明较完整；挠度与弯矩以线上页为准，专题公式页仍在补充。工具输出不能替代有资质的结构计算书。
