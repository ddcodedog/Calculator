# PMV、PPD 与空调负荷：热舒适与负荷估算

[HVACEngineerLab](https://hvacengineerlab.com) 侧重暖通方案阶段的在线计算。方案比选里，热舒适指标与空调负荷通常最先被问到。

优先主题对应工具：

- **PMV** — [Thermal Comfort PMV Planner](https://hvacengineerlab.com/tools/thermal-comfort-pmv-planner/)：按空气温度、平均辐射温度、风速、湿度以及服装热阻、代谢率等估算预测平均投票。
- **PPD** — 清单中暂无独立工具页；PPD 一般与 PMV 成对给出，请在上述热舒适规划器界面查看输出，或从 [站点首页](https://hvacengineerlab.com) 浏览工具列表。
- **空调负荷** — [Cooling Heating Load Planner](https://hvacengineerlab.com/tools/cooling-heating-load-planner/)：用于冷/热负荷规划阶段的量级估算。

上述 URL 均来自生产站工具清单。对应开源公式专题仍在补写，现阶段以线上计算器与项目假设为准；正式负荷与舒适度验收应遵循当地规范与实测条件。
