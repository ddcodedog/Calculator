# 流量、管径与压力损失：给排水水力快算

[WaterEngineerLab](https://waterengineerlab.com) 面向给排水与雨洪的在线水力计算。方案阶段三条主线是流量、管径与沿程压力（水头）损失。

优先主题对应工具：

- **流量** — [Manning Open Channel Flow](https://waterengineerlab.com/tools/manning-open-channel-flow/)：按曼宁公式估算明渠过流；管道可配合 [Water Pipe Flow / Headloss](https://waterengineerlab.com/tools/water-pipe-flow-headloss/)。
- **管径** — [Pipe Diameter Sizing](https://waterengineerlab.com/tools/pipe-diameter-sizing/)：按目标流量与允许流速（或水头损失）辅助选型。
- **压力损失** — [Water Pipe Flow / Headloss](https://waterengineerlab.com/tools/water-pipe-flow-headloss/)：估算沿程水头损失；静压/余压见 [Pressure / Static / Residual Check](https://waterengineerlab.com/tools/pressure-static-residual-check/)。

明渠流量与管道水头损失有对应公式说明；管径选型以生产站为准。正式设计需计入局部损失与地方标准。
