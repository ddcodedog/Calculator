# How to cite a topic

Cite the note as a checked calculation record. Do not cite it as a ranking, a traffic result, or a statement that a design code was satisfied unless the standards status is VERIFIED and the section you cite was actually read.

## What to include

- Site name and production tool URL from the topic's Online Calculator section
- Tool id
- Repository path of the English topic, and the Chinese companion path when you used that file
- Calculation status and standards status
- Verification date printed in the topic
- The example inputs and outputs you relied on

## Example

NetEngineerLab tool `optical-power-budget`, topic `NetEngineerLab/optical-power-budget.md`, Chinese companion `NetEngineerLab/optical-power-budget.zh-CN.md`. Calculation status VERIFIED on 2026-11-04 from production `engine.js`. Standards status PENDING. Worked example: design loss 11.40 dB, remaining budget 17.60 dB.

## What not to do

- Do not cite a homepage when the topic names a tool URL.
- Do not collapse calculation status and standards status into one claim.
- Do not point a Chinese reader at an English tool URL when the Chinese page was checked. For NetEngineerLab that page uses `/tools/<slug>/zh/`.
- Do not add a standard number that the topic does not already cite.
